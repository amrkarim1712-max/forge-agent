# Forge Agent project instructions

This file is an example of the project-level instruction surface that Forge reads when operating in a repository. Keep it focused on conventions, commands, architecture boundaries, and verification expectations. It is project input, not a replacement for Forge's safety rules.

## Example conventions

- Prefer small, reviewable changes.
- Run the relevant tests before reporting completion.
- Never commit secrets or generated credentials.

Projects using Forge can replace this file with their own instructions.
